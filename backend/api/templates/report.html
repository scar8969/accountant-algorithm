Guarantees enforced in code

  • Participant-grouped split; pairs straddling folds are dropped, never split.
  • Features never read labels or post-interaction feedback.
  • Unshown or unanswered directions are unknown, never negative.
  • Mutual interest requires both sides; one row per pair.
  • Every prediction records model and feature-schema versions.

Methods and limitations

Pre-registered hypothesis

{{ view.experiment.hypothesis }}

Primary metric

{{ view.experiment.primary_metric }}, held-out participants, 95% cluster bootstrap over participants. Positive prevalence is reported alongside it; multiple metrics are reported so no single one can be cherry-picked.

Score semantics

The 0-100 score is an experimental scale, not a probability. Each score carries an evidence level and a weight-sensitivity band (±25% perturbation of pre-registered weights, 200 deterministic draws) — sensitivity to the weights, not sampling uncertainty.
